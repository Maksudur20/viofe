# viofe

> Pure HTML, CSS & Vanilla JavaScript Edition of **VIOFE** — Handwoven Sarees & Heirloom Jewellery.

A complete, pixel-perfect, framework-free luxury website built purely with **HTML5**, **CSS3**, and **Vanilla JavaScript** (Zero dependencies, Zero CORS restrictions, works seamlessly on both `file:///` and `http://`).

---

## 🌟 Pages Included

1. **`index.html`** — Homepage with hero section, rotating announcement bar, ken-burns banner, animated marquee ticker, interactive collections grid, featured heirloom pieces, editorial chapter, atelier story, new arrivals, testimonials, and trust promises.
2. **`shop.html`** — Complete catalog with real-time category filtering (`?category=sarees/bangles/...`), live search, price band filters, and sorting.
3. **`product.html`** — Detailed product page (`?slug=...`) with image gallery switcher, option selector (Blouse, Size, Finish), quantity stepper, stock status, accordion information (Details, Care, Shipping), Add to Bag, and Related Products.
4. **`cart.html`** — Shopping bag page with item review, individual quantity adjustments, gift wrap toggle (+৳ 350), complimentary shipping progress meter, order totals, and checkout trigger.
5. **`checkout.html`** — Multi-step checkout with form validation (Contact, Delivery Address, Delivery Method: Standard vs Express, Payment Method: COD, bKash/Nagad, Card), order generation, and interactive order confirmed screen.
6. **`track-order.html`** — Real-time order tracking with 6-stage visual progress stepper (Placed, Confirmed, Crafted & packed, Shipped, Out for delivery, Delivered) and item breakdown.
7. **`about.html`** — The Maison's story, artisan philosophy, 3 core pillars, timeline, and atelier gallery.
8. **`contact.html`** — Client care contact form with topic pills, flagship boutique details in Gulshan 2, Dhaka, and private styling booking.
9. **`login.html`** — Authentication page with smooth toggle between "Sign in" and "Create account", saving state to browser `localStorage`.
10. **`account.html`** — Member account dashboard featuring placed orders, saved wishlist items, saved addresses, and profile editing.
11. **`admin.html`** — Atelier Admin Dashboard featuring KPI statistics, interactive SVG revenue area chart, category sales breakdown, low stock alerts, full orders management with live status updater dropdown, product inventory, and customer directory.

---

## 🚀 How to Run

You can open `index.html` directly in any web browser by double-clicking it (offline support via `file:///`), or host it on **Cloudflare Pages**, **GitHub Pages**, or **Vercel** with zero build configuration!

## 🎨 Design System
- **Colors**: Deep Maroon (`#4A1520`), Warm Cream (`#F6F3EC`), Ivory (`#FAF8F5`), Metallic Gold (`#C6A052`)
- **Typography**: *Cormorant Garamond* (display serif) & *Jost* (clean sans-serif)
- **Features**: Slide-out cart drawer, mobile navigation drawer, toast notifications, localStorage persistence for bag, wishlist, accounts, and orders.
